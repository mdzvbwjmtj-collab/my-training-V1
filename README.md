# My Training V1

Mobile-first training tracker built around the user's four-day Upper / Lower programme.

## Current MVP
- Today view with set-by-set workout completion
- Four-day Upper / Lower programme
- Upper-chest priority cues for machine chest press and incline pressing
- Technique and progression guidance per exercise
- 2,400 kcal and 200 g protein targets
- Bodyweight logging and recent-weight history
- Browser local persistence

## Use
Open `index.html` directly or deploy the repository with GitHub Pages.
